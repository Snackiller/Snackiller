## 🚀 Featured Projects

### 🤖 Multilingual AI Chatbot — Northwestern ECE

A multilingual retrieval-augmented generation (RAG) system built to help students, faculty, and prospective applicants find department information.

- Supported **1,000+ users** across **18 inquiry categories** with a JavaScript widget, Flask APIs, analytics, and session persistence
- Built a fault-tolerant ingestion pipeline for **26 university knowledge files**, improving ingestion coverage from **96.2% to 100%**
- Reduced representative query latency by **60% (15s → 6s)** using startup preloading and reuse of a **714K-vector FAISS index**

**Tech:** Python · Flask · JavaScript · FAISS · RAG · OCR

### ⚡ Real-Time Multi-User Bill Splitting Platform

A real-time application for coordinating shared bill payments and handling concurrent item claims.

- Implemented live synchronization using **STOMP messaging** and **GraphQL snapshots**, achieving approximately **16 ms p95 claim-event propagation latency**
- Used **JPA pessimistic locking** and transactional workflows to prevent conflicting claims on the same bill item
- Added a policy-constrained lightweight agent to handle eligible unclaimed items when participants become inactive

**Tech:** Java · Spring Boot · STOMP · GraphQL · JPA

### 🛡️ AI-Assisted Scam Analysis — Allstate Identity Protection

An industry-sponsored software engineering project focused on analyzing potentially fraudulent text and image submissions.

- Combined **OCR, regex extraction, GPT-assisted reconciliation, and HTTP risk evaluation** in an automated analysis pipeline
- Built explainable risk-analysis interactions and scan-to-chat follow-up
- Added recovery paths for third-party service failures to improve workflow continuity

**Tech:** OCR · LLM Integration · REST APIs
